# Sales Trends Analysis Dashboard

## Overview
This repository contains the "Sales Trends Analysis Dashboard," which analyzes historical sales data to uncover trends and generate actionable insights. The project incorporates techniques like data preprocessing, exploratory data analysis (EDA), visualization, and predictive modeling using Python, Power BI, and SQL.

## Objectives
- Analyze sales trends over multiple financial years.
- Explore demographic, product, and program factors influencing consumer behavior.
- Develop predictive models to forecast future sales.
- Enhance resource allocation and strategic planning using insights derived from the data.

## Features
- **Data Preprocessing**: Includes cleaning, normalization, and encoding of sales data.
- **Visualizations**: Dynamic charts, graphs, and dashboards showcasing sales metrics like revenue, profit, and product popularity.
- **Predictive Models**: Linear Regression and Logistic Regression models for forecasting sales trends and analyzing consumer behavior.
- **Interactive Dashboard**: Built using Power BI, with filtering, sorting, and detailed metrics.

## Dataset
- **Details.csv**: Contains sales transaction data (Order ID, Amount, Profit, Category, Sub-category, Payment Mode, etc.).
- **Orders.csv**: Includes order information (Order ID, Order Date, Customer Name, State, City).
